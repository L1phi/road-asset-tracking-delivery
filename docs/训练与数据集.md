# 训练与数据集

## 1. 随库数据

`data/road-assets737`包含858张真实原图及审核后的YOLO标签：737张训练、3,447框；121张测试、588框。原图逐张SHA256与冻结manifest核验，训练和测试没有精确内容hash重叠；没有据此声称排除了近重复或同视频泄漏。

| 路径 | 用途 |
|---|---|
| images/train_original + labels/train_original | 737张审核原图与最终GT |
| images/train_videoquality + labels/train_videoquality | 按保存配方重建的视频画质训练数据；生成后提供 |
| images/test + labels/test | 121张原始画质测试图与588框，未降质 |
| dataset_manifest.json | 原图/标签SHA256、最终boxes和对应关系 |
| videoquality_manifest.json | 重建降质图SHA256和使用的库版本 |
| audit.json | 数量、精确hash重叠及导出范围 |

训练GT不是旧803标签简单裁剪：737来源于803训练记录的去重与人工审核，删除66条重复记录并修正个别标注。用最终审核boxes导出YOLO标签，不混用不同版本。固定17类顺序见`config/classes.json`，其中SM无训练/测试样本、CS训练2框但测试0框、XHD训练4框测试1框。

原始val120已并入训练来源，因此没有独立验证集。训练val=false、patience=0，不看test选择最佳轮次。配置中val指向训练图只用于框架路径要求，不能把该结果称为独立验证成绩。

## 2. 737B画质处理

每张训练原图转RGB，等比例缩到不超过1920×1080，不放大、不裁切；LANCZOS缩放；输出像素尺度Gaussian sigma=.6；再按历史视频第10帧记录的JPEG量化表与subsampling=2编码。归一化GT保持不变。

本次已随库提供737张重建版B训练图，通常不需要再运行准备脚本。`python prepare_videoquality.py`用于从未生成B图的数据副本重新构造，已有输出会拒绝覆盖。脚本只处理train_original，不改test。重建文件与当年配方一致，但缺少当年的逐图降质hash，且编码库版本可能不同，因此manifest明确标记为配方重建，本次重建文件使用独立哈希记录，与历史降质文件未作逐字节比对。

## 3. 检测网络怎么训练

历史训练：Ultralytics8.4.146、PyTorch2.6.0+cu124、H20，YOLO26l非P2，从通用`yolo26l.pt`独立初始化，不从旧803/A版/当前737B继续训练。全参数训练；训练前检查one2many/one2one的box与cls分支都有非零有效梯度。

| 参数 | 值 |
|---|---|
| epochs / batch / imgsz | 100 / 9 / 960 |
| seed / deterministic / amp | 42 / true / true |
| optimizer / cos_lr / warmup_epochs | auto / true / 3 |
| workers / cache / resume / freeze | 0 / false / false / null |
| patience / val / close_mosaic | 0 / false / 10 |
| hsv_h / hsv_s / hsv_v | .015 / .5 / .35 |
| degrees / translate / scale / shear | 2 / .08 / .35 / 1 |
| perspective / fliplr / flipud | .0002 / .5 / 0 |
| mosaic / mixup / cutmix / copy_paste | .7 / .05 / 0 / 0 |

完整实际参数见`training/args_original.yaml`，100轮损失与学习率记录见`training/results_original.csv`。`optimizer=auto`下，不能把yaml的lr0当成一定生效的实际学习率；应查看日志/每轮LR。仅使用epoch100 `last.pt`，不是根据test择优选择`best.pt`。

## 4. 从头复现步骤

在README的Python3.11/GPU环境中执行，输出保存到新实验目录。

```bash
# 原图及GT已随LFS交付；重建视频画质训练图（已存在则拒绝覆盖）
python prepare_videoquality.py

# 获取通用预训练权重，不是当前道路资产last.pt
gh release download v8.4.0 --repo ultralytics/assets --pattern yolo26l.pt --dir models

# 先校验，再启动新训练；输出目录必须不存在
python train.py --base models/yolo26l.pt --output outputs/retrain-737b --check-only
python train.py --base models/yolo26l.pt --output outputs/retrain-737b
```

通用预训练权重SHA256必须为`9fe3c544f2b19bebad7ea41e76d7ad3d88b7c2f10d11d24430c5311f6b32db26`。缺少时下载；已训练的`models/last.pt`用于推理。新训练输出为`outputs/retrain-737b/train/weights/last.pt`，不会覆盖交付权重。

本次已补齐并核验该通用预训练权重，若`models/yolo26l.pt`已经存在且哈希正确，应跳过上述下载命令；同理已有train_videoquality时跳过重建，直接检查和训练。

`train.py`复用实际args，重定位路径和输出目录，保留历史增强、双分支梯度探针、训练轮数验证。新增包装脚本尚未重新启动100轮训练，对应训练运行结果另行记录。

## 5. MoCo与追踪规则怎么训练

本项目**没有训练或微调MoCo**；使用MoCo v3 ResNet50 1000ep预训练base_encoder去掉fc，输出2048维L2特征。没有资产身份监督的ReID训练集，也不声称其已学习道路专用身份。NMS、图关联、类别规则是工程规则，不是训练出的网络；参数调整不等于重新训练。

## 6. 评估口径

- 原生检测：Ultralytics val，test121原图，imgsz960、batch9、conf=.001候选下限、NMS IoU=.7、nms=true；报告各类AP与mAP。
- 统一P/R/F1：在保存的逐框预测中过滤confidence≥.359；同类别IoU≥.5，按IoU降序贪心一对一匹配；Micro汇总框，Macro对15个有GT类别平均。12小类排除BS/HL/LH，不是按面积定义的小目标。
- 测试GT中的缺失类别不伪造召回，少样本类别不可据一次高分断言稳定性。原生P/R的工作点与固定.359不一样。
- 历史737B结果见`docs/test121_metrics.json`。随库GT可用于重新评估，但不能用test调阈值后仍称独立测试。

运行`python evaluate.py --output outputs/test121-evaluation`评估交付权重；测试新训练模型时加`--weight outputs/retrain-737b/train/weights/last.pt`。输出`metrics.json`分别保存原生指标和固定阈值P/R/F1，逐框预测保存在native/labels。运行前需完成训练/推理环境安装；本次交付整理没有重新跑此GPU评估。
