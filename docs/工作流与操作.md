# 工作流与操作手册

## A. 部署和输入检查

1. 获得Private仓库权限，安装Git LFS，克隆并执行`git lfs pull`。
2. 按README在独立Python3.11/CUDA环境安装依赖、系统libGL和GLib，执行`pip check`。
3. 执行`python run.py --verify-package`核验交付程序与原始训练/测试集。重新生成的降质图另有自己的manifest，不伪装成历史文件。
4. 准备目录顶层的1920×1080、10FPS `.avi`。不支持自动改变帧率/分辨率，不能把任意原录像当作已满足条件。
5. 使用`python run.py --check-only --input /data/videos --output /data/job-001 --profile h20`检查。4090系列改为4090；输出目录必须是新路径。
6. 按README执行MoCo实际GPU检查。上述输入检查不等于已做MoCo推理或视频准确率验收。

## B. 正式推理的实际顺序

| 顺序 | 处理 | 中间结果 |
|---|---|---|
| 1 | 解码，YOLO检测，同时GMC | 原始框与相邻帧变换 |
| 2 | 置信度≥.359，排除HL/LH；非BS先分类NMS | 初步观察框 |
| 3 | 同类几何候选、竞争与断帧恢复候选 | 允许连接与MoCo需求 |
| 4 | BS前后实际完整框—子框候选 | 不依赖先验正确轨迹的身份假设 |
| 5 | 汇总整框MoCo需求，读取裁剪、批量提特征 | 归一化2048维向量 |
| 6 | 合格BS候选再提局部MoCo并验证 | 大小框接受/拒绝关系 |
| 7 | 利用证据做最终同帧NMS | 最终观察框 |
| 8 | 按类全局图求解，路灯只用几何 | 基础轨迹 |
| 9 | 应用BS共享身份、ZH连续高置信度规则 | 最终轨迹 |
| 10 | 每视频每类独立编号，保存JSON和日志 | 可审计输出 |

运行：`python run.py --input /data/videos --output /data/job-001 --profile h20`。默认YOLO batch=1、MoCo batch=32，不启用未经新入口验收的多进程调度。不要把历史H20 y32/m512/d4/t4的2.05秒/10秒，直接当本入口单进程承诺。

## C. 输出怎么读

- `results/<视频名>_tracks.json`：`predictions`以0起始帧号为键；`box`是原图xyxy像素，`confidence`是检测置信度，`class_id`为固定17类之一，`id`为内部身份。
- `display_map`是类别独立显示编号映射；BS1与LD1无身份关系，不同视频的BS1也不能直接合并。
- `class_statistics.IDs_not_inventory`是输出ID数，不是经GT验收的道路库存；跨视频未去重。
- `NMS_audit`、`association_audit`、`parent_audit`、`ZH_audit`记录为何删除框、连接、共享身份或确认桩号。
- `execution.log`是完整运行日志；`invocation.json`记录输入hash与实际参数；`_runtime`是本次运行模块和输入manifest快照。
- 不提供已删除的可视化视频。若新增渲染器，只允许读结果画框，不能偷偷补框或更改ID。

## D. 训练和评估

完整步骤见《训练与数据集.md》。关键顺序：核验原图/GT → 按配方生成train_videoquality → 获取指定COCO预训练权重 → 检查GPU/双分支梯度 → 独立训练100轮 → 固定epoch100 last.pt → 用test121一次性报告原生mAP与固定阈值F1。不得用test选择轮次、阈值或增强。

## E. 故障处理

| 现象 | 处理 |
|---|---|
| 下载下来只有几行LFS文字 | 执行git lfs pull，检查仓库权限与配额 |
| 包校验失败 | 确认LFS真文件和manifest来自同一提交，不跳过哈希 |
| libGL.so.1缺失 | 运维安装系统依赖，不混装多个cv2发行包 |
| CUDA不可用/版本错误 | 核对GPU驱动、PyTorch CUDA与冻结版本，不静默跑CPU |
| 输入帧率/分辨率错误 | 单独预处理并记录映射后再输入，别改manifest骗过检查 |
| 输出目录已存在 | 换新任务目录，避免覆盖结果 |
| 长视频内存增长 | 停止扩大规模，按验收计划评估分段与跨段身份；本版不承诺长视频 |
| 有轨迹但计数不对 | 检查GT、漏检/重复框、串号/断轨和跨视频重叠，不只调数量阈值 |

## F. 验收与运行边界

交付代码没有被包装成服务/API，也没有生产队列、权限系统、跨视频库存系统。新增入口在本地完成静态测试，目标GPU端到端、新视频计数和长视频压力验证按验收清单完成后再上线。
